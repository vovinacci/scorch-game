# Scorch roadmap

What's done is described in `GUIDE.md`. What's next lives in GitHub issues, so each item can be discussed and closed by
the pull request that ships it:
[planned work](https://github.com/vovinacci/scorch-game/issues?q=is%3Aissue+is%3Aopen+label%3Aplanned) and
[ideas](https://github.com/vovinacci/scorch-game/issues?q=is%3Aissue+is%3Aopen+label%3Aidea).

## Where it's going

Scorch aims to be the original's battles, weapons and bots, with today's comfort: any window size, keyboard or mouse,
saves, signed updates, two languages. Roughly in order of fun per effort:

- **A bigger field:** more than four tanks, and teams ([#47](https://github.com/vovinacci/scorch-game/issues/47)), and
  modes where everyone aims at once ([#48](https://github.com/vovinacci/scorch-game/issues/48)).
- **More of the original's arsenal:** bigger and smaller versions of the weapons we have
  ([#136](https://github.com/vovinacci/scorch-game/issues/136)), weapons that work in new ways such as the Sandhog,
  Liquid Dirt and the Laser ([#137](https://github.com/vovinacci/scorch-game/issues/137)), and the original's game
  options and remaining items ([#138](https://github.com/vovinacci/scorch-game/issues/138)).
- **Character:** talking tanks ([#49](https://github.com/vovinacci/scorch-game/issues/49)) and the remaining touches: an
  Unknown bot, a cavern sky, erratic walls, flying dirt, whistling shells
  ([#140](https://github.com/vovinacci/scorch-game/issues/140)).
- **Easier to get and play:** a Windows installer ([#45](https://github.com/vovinacci/scorch-game/issues/45)) and a
  browser build ([#46](https://github.com/vovinacci/scorch-game/issues/46)).

Labels: `planned` (we intend to build it), `idea` (a suggestion, not decided), and an area: `weapons`, `bots`,
`gameplay`, `platform`.
